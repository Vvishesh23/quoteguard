# Data provenance

`synthetic.jsonl` is generated by `quoteguard.fixture.generate(seed=17)`.
It is SYNTHETIC, uncalibrated, and never a recorded market session.

Each JSONL envelope contains source, UTC receive nanoseconds, a human-readable UTC
receipt string, monotonic receive nanoseconds, and raw unmodified WebSocket text.
The synthetic clock is deterministic. Live capture uses actual system clocks.
Trade exchange event/trade times remain in the raw payload and parsed outputs.
Book ticker update IDs are preserved; no exchange timestamp is invented.

Live captures are ignored by version control by default. Their adjacent `.meta.json`
records connection attempts and failures. A raw record being preserved does not
mean it passed validation. Consult the analysis summary for rejected counts.
